# TrackWise - Frontend

React + Vite frontend for the TrackWise mentor/mentee portal.

## Pages
- Login
- Register
- Mentor Dashboard
- Mentee Dashboard
- My Mentees
- Student Profile
- Meetings
- At Risk Students
- Bulk Alerts
- Reports
- Mentor Profile

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

This version is a frontend-only implementation with demo/static data. Backend APIs and database integration can be connected later.
